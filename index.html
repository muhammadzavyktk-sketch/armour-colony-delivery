Install Armour Delivery App

Same-day delivery app for iOS, Android & Windows

Safari Instructions

Apple iOS allows quick PWA installation directly through Safari in 3 simple steps.

  1. 1
    Tap the Share Button

    In Safari, tap the Share icon ⎋ at the bottom (or top on iPad) of your screen.

  2. 2
    Select "Add to Home Screen"

    Scroll down the share sheet and tap "Add to Home Screen" ＋.

  3. 3
    Tap "Add" in Top Right

    Confirm the app name and tap Add. Armour Delivery will now launch like a native app!

Android PWA

Install directly to your Android home screen for instant orders & offline access.

or install manually via Chrome menu:
  1. 1
    Open Browser Menu

    Tap the 3 vertical dots (⋮) in Chrome / Edge top right corner.

  2. 2
    Tap "Install App" or "Add to Home Screen"

    Select Install App from the menu choices.

  3. 3
    Confirm Install

    Tap Install to place the Armour Colony Delivery app icon on your phone.

Windows / Desktop

Run Armour Colony Delivery in its own desktop window on Windows, Mac, or ChromeOS.

or install via browser address bar:
  1. 1
    Check Browser Address Bar

    Look at the right edge of your Chrome/Edge URL bar for the Install ⊕ / Computer icon.

  2. 2
    Click "Install"

    Click the icon or open browser menu ➔ "Install Armour Colony Delivery..."

  3. 3
    Launch from Start Menu

    You can now open the app anytime directly from your Windows Start Menu or Desktop shortcut!
